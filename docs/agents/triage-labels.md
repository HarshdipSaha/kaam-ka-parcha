# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is needed. |
| `needs-info` | `needs-info` | Waiting for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for implementation. |
| `ready-for-human` | `ready-for-human` | Requires a human decision or action. |
| `wontfix` | `wontfix` | Will not be actioned. |
